# midhulafarmhut

Landing page for **Midhula Farm Hut** — an interactive, top-down koi pond.

- Real-time water simulation (WebGL) with ripples, refraction, caustics and reflections
- Procedurally drawn koi, goldfish, small schooling fish, a turtle, a dragonfly and water lilies
- Move through the water to make ripples; click or tap to feed the fish
- Adaptive quality so it stays smooth on phones and older laptops

Plain HTML/CSS/JS — no build step. Open `index.html` or serve the folder:

```sh
python3 -m http.server 8080
```
